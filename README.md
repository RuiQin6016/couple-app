# 恋爱小管家 💕

给两个人用的**私用小应用**。纯网页，装到手机桌面上就是一个 App —— 图标、独立窗口，没有浏览器地址栏。

> 这是**自用**项目，不商用、不公开发行。代码开源在这里，欢迎参考，但请注意下面的「引用与授权」。

---

## 它有什么

| 功能 | 说明 |
|---|---|
| 💌 **每日情话** | 454 条语料（历代诗词 + 现代名家）。**同一天两个人看到的是同一句**，按日期取模，不是随机 |
| 📅 **恋爱纪念日** | 总天数 / 年·月·日拆解 / 下一个周年倒计时 / 进度条。**改一次两个人同步变** |
| 🌤️ **两人天气** | 各自身边什么天气，**不用选城市**（定位 → 经纬度直接查） |
| 🗓️ **情绪日记** | 8 种心情 + 每天两人各写一篇日记。日历上**方形=我 / 圆形=TA**，点日期补记 |
| 💬 **悄悄话** | 两个人之间的私密对话，带未读和已读 |
| 🐷 **桌宠小猪「糯米」** | 会饿会脏会困，可以拖着走，只在首页出现 |
| 🌸 **例假记录** | 记录 + 周期预测（**明确不做排卵期/易孕期断言** —— 精度不足以支撑避孕备孕，那是误导） |
| 📷 **共同相册** | 两个人一起传照片，可以各自选择哪些不展示 |
| 🎁 **积分商城** | 签到攒积分，兑换「陪陪我 / 一起弄 / 见面」这类东西 |

**正在做的**：情绪日记的点日期面板、悄悄话的对话页（首页两张卡已经在了，点进去的页面还在做）。

## 怎么装到手机（不用装任何开发工具）

### 安卓（你的手机）
1. 用 **Chrome** 打开网页地址
2. 右上角菜单 → **「安装应用」**（或「添加到主屏幕」）
3. 桌面出现图标，点开就是独立窗口

### iPhone（对方的手机）
1. **必须用 Safari** 打开（Chrome 不行）
2. 底部 **分享** 按钮 → **「添加到主屏幕」**
3. 桌面出现图标

> ⚠️ 两边都要走 **https**。直接双击 html 文件用（`file://`）装不了，同步也用不了 ——
> 浏览器在 `file://` 下每个窗口的存储是隔离的，端到端加密也受限制。

## 隐私：你们的内容**不在这个仓库里**

这是这个项目最重要的设计：

```
明文（日记/悄悄话/纪念日） → 在手机上加密 → 上传
                                ↑ AES-256-GCM + PBKDF2 20 万次
服务器（GitHub 私有 Gist）上只有密文
```

- 这个仓库里**只有程序代码**，没有任何聊天记录、日记、照片
- 密钥（口令）**只存在你们两台手机的本机**，不写进代码、不上传
- **GitHub 自己也只能看到密文**（有自动化测试守着这条：密文里搜不到任何明文）
- 私有 Gist 的"私有"= 不公开列出；**知道链接的人能看到内容，但看到的是密文**，没有口令解不开
- 口令是随机生成的 24 字节，不需要你们记，也不怕被猜

**唯一要保管好的两样东西**：配对用的**链接码**（`CPL1...`，等于邀请函，别公开发）和 **GitHub token**。

## 自己配一份要填什么

### 1. 天气（高德 Web 服务 key）
天气接口需要一个高德 key。**它不存在代码里**（仓库公开），而是存手机本机，在 App 的「设置」里填一次。

申请：<https://console.amap.com/dev/key/app> → 创建应用 → 添加 Key → **服务平台必须选「Web服务」**
（选成 JS API 会报 `USERKEY_PLAT_NOMATCH`）
免费额度：天气 5000 次/月、逆地理编码 15 万次/月 —— 两个人自用一天 2~4 次请求，用不到千分之一。

### 2. 同步（GitHub 私有 Gist）
1. GitHub 建一个**细粒度 token**，权限只勾 **Gists: Read and write**（别给别的）
2. 在 App 的「设置 → 同步」里粘贴 token，点「我是第一个」→ 生成**链接码**
3. 把链接码发给对方，对方在设置里点「对方已经配好了」→ 粘贴 → 完成
4. 之后两边**永久免输**（配置存本机）

> 两台设备的「口令指纹」（形如 `8234-F7C2-3DE3`）对一下就知道能不能互相解密，
> 不用等同步失败才发现。

#### 万一配错了 / 换了手机：设置里的「接入已有的云端」
在设置 → 同步里有一个 **「接入已有的云端（换设备 / 配错了）」**：填
**GitHub token + 云端 ID**，让**这台**手机直接接上那个**已经存在**的云端。

它和「粘贴链接码」的区别很重要：

- **身份（A / B）一个字都不改**。粘贴链接码那条路会把设备**写死成 B**，
  所以"一直是 A"的那台没法用它修（一粘就变 B，两人的日记/心情会互相顶）。
- **先空读一次云端验证**，读得通才写进配置 —— 拼错 token / 云端 ID 时
  **不会把配置改坏**（不会留下"看着配好了、其实什么都同步不了"的状态）。

> 「云端 ID」在**已经连上的那台**手机上看：设置 → 同步 →「云端 ID」（前 8 位够用）。

#### 怎么一眼看出"配错了"（真机上踩过）
如果一台手机的「**云端 ID**」是空的、而体检里写着 **「云端：还没有数据」**，
说明它压根没连上 GitHub（多半被配成了「只是在本机两个窗口试一下」，那走的是
`provider: 'local'`）。**注意它的「写入闸门」可能照样显示绿灯**——local 模式下
"读到自己本机的空槽位"也算成功，于是那个绿灯是假的。这种情况就用上面的
「接入已有的云端」接回去。

**同步速度**：客户端每 20 秒轮询一次（打开对话页时 5 秒）。
**没有服务端推送，所以 App 关着的时候收不到提醒** —— 做不到微信那种秒到，这是当前架构的硬边界。

## 技术栈

- **纯 HTML + 原生 JS**，零依赖、零构建（没有 npm install，没有打包步骤）
- PWA（manifest + service worker），可装到桌面
- 同步：GitHub 私有 Gist + 端到端加密
- 自测脚本：加密 27 项 / 同步 36 项 / 链接码 56 项 / 情绪日记 104 项 / 悄悄话 57 项 / 双设备同步 52 项，`node tools/test-*.js` 直接跑

### 踩过的坑（都写进代码注释了）
GitHub Gist 的 `PATCH` 不接受 `If-Match`（任何写法都 400）、409 是**偶发**的（不能当唯一并发保护）、版本标记只能用 `updated_at`。
所以写入走「先 GET 比对 `updated_at` → 发现对方写过就先合并再写 → 409 只当兜底重试」。
